Abstract. AlphaEvolve is an evolutionary coding agent that improves algorithms by making direct code changes, with evaluator feedback. Applied at Google to datacenter scheduling, accelerator circuits, and LLM training. Discovered a 4×4 complex matrix multiply using 48 scalar multiplications, the first improvement over Strassen in that setting in 56 years.
