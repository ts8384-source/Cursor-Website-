Abstract. MemoryBank is a long-term memory mechanism for LLMs that summons relevant memories, updates them continuously, and adapts to a user personality over time. To selectively preserve memory it uses an updating mechanism inspired by the Ebbinghaus forgetting curve, forgetting and reinforcing based on elapsed time and relative significance.
