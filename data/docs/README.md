# Framework doc wiki

This directory is the **doc wiki** (framework explanation). It is not the boot / user project wiki.

- Boot wiki: `data/md/` → `/site/...`
- This wiki: `data/docs/` → `/docs/...`

Delete this folder to drop the doc site. The boot wiki still runs. Papers and boards are not in this folder.

One-click in the UI: **Remove doc wiki** (Are you sure?) → `POST /api/docs/remove`.
