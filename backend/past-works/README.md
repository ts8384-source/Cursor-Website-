# Past works (backend)

Sibling archive from `../Old` (thesis, documentations, literature notes, conversation index).

Files live in `data/past-works/`. This folder is the API + index, not a second copy of the Markdown.

- `GET /api/past-works` — catalog + counts
- `GET /api/past-works/facts` — fact layer on top of those MDs
- `GET /api/past-works/dialect-tree` — analog/dialect paper tree
- `GET /api/past-works/file?path=` — one archived MD (path-jailed)

Do not treat Gemini numeric tables as measurements. Unverified citations stay marked.
